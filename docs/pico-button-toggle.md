# Pico 第8課：按一次切換 LED

2026-11-09（Asia/Taipei）。新課ID為button-toggle，Pico現有8課、11篇Wiki，三板型共44課。入口：`?board=pico-2-w&lesson=button-toggle#intro`。

沿用GP14（實體19）PULL_UP按鈕、GP15（實體20）與220Ω／LED的五條接線、按鈕3D與鍵盤端點，不新增硬體。放開讀1、按下讀0；四腳按鈕需跨A／B兩側。接線仍檢查限流、極性、斷路、短路、同側接法與錯誤GPIO。

標準練習在迴圈前關燈並將previous初始化為1。每20ms將button.value()存入reading，只有reading小於previous（1→0）才toggle，最後更新previous。長按與放開不切換，下次按下才再切換。啟動時若已按住，第一個低樣本也視為按下。使用者的判斷順序／間隔仍決定實際行為，不是固定動畫。

預設只提供物件、初始化及pass；完整答案需主動展開。新課支援按鈕value()數值算式、32位元整數變數與單層比較；既有七課白名單不擴張。保留來源、操作、陳述及時間預算，不執行任意Python。補全跟隨物件改名與狀態變數，Wiki解釋前次樣本、下降邊緣、漏讀及機械彈跳。

觀察區顯示即時／上次按鈕讀值、變數與LED數位波形。暫停保留程式狀態，改輸入後於繼續時才取樣；步驟、Wiki與匯出保留編輯器／場景／執行狀態。切換步驟釋放暫時按住的按鈕，保持按下勾選沿用。按鈕保持狀態不寫入JSON，還原不自動執行。

JSON保留v1與獨立課程草稿鍵，舊課資料不變。main.py仍只匯出目前使用者程式與說明，保留註解，不要求接線完成；未完成或不支援程式以行列診斷阻擋下載。

本課是理想按鈕取樣，20ms等待不是實板去彈跳。真實開關可能有多次邊緣，需另做穩定時間判斷與實測；完整按放發生在兩次取樣之間可能漏讀。沒有新增中斷、ticks_ms、硬體連線或可靠警報功能。
