# Sprint 3：單顆外接 LED 教學契約 v0.1

日期：2026-10-27（Asia/Taipei）。沿用 ESP32-DevKitC V4／ESP32-WROOM-32E，單板 38 Pin。使用者已要求開始外接 LED 接線教學，沿用既有 GitHub Pages 試用版更新流程。

> 本文件保存 Sprint 3 的手動接線契約；新增程式分頁的規則另見 [Sprint 4 契約](program-lesson.md)。

## 可操作範圍

- 保留原「接腳探索」，新增「LED 接線」分頁；網址 `#led` 可直接進入課程。
- 一顆固定 220 Ω 電阻、一顆有明確 A+／K− 標示的紅色 LED、最多 12 條導線。零件不拖動、不增減數量。
- 點兩個模型端點接線，也可用原生按鈕及鍵盤操作；再次選相同起點、取消按鈕或 Escape 可取消。禁止自連、未知端點及無方向意義的重複接線。
- 每條導線有獨立 ID 與刪除按鈕；清空接線將輸出回到 LOW。「載入範例」建立 GPIO23 → 電阻 A、電阻 B → LED A+、LED K− → J3-01，輸出設為 LOW。
- GPIO23 固定為本課的 OUTPUT，手動 HIGH／LOW 不執行使用者程式。只有有效拓撲且 HIGH 時亮起。
- 接線及電位只暫存目前頁面記憶體；切換分頁會保留，重新整理會清空。無上傳、localStorage 或跨裝置同步。

## 資料分層

`board` 定義原實體腳位；`lessonDefinition` 定義固定來源、220 Ω、LED 與可用接地；`CircuitWire[]` 保存端點圖；`CircuitState` 保存導線、待接起點及輸出電位；`CircuitAnalysis` 是衍生結果。Three.js 幾何與介面讀取同一份圖狀態，不以發光材質反推電路有效性。

原生控制器由 reducer 處理新增、刪除、取消、載入與清空。純分析函式不依賴 React／WebGL；即使 WebGL 不可用，接線清單、診斷及亮滅文字仍能操作。

## 凍結的離散規則

- 只有 J3-02／GPIO23 與三個 GND 可作本課板端。每個 GND 仍有獨立 pinId，電氣分析時共地。
- 電阻沒有極性；A/B 交換、導線建立方向及順序不影響結果。電阻可在 LED 前或後，只要串聯於同一路徑。
- LED A+ 朝 GPIO23、K− 朝 GND；反向串聯明確回報極性反接，不亮。
- GPIO23 直接接 GND、跨接電阻、短接 LED 都明確診斷，不亮。
- LED 直接跨 GPIO23/GND 而無串聯電阻，回報缺少限流電阻，不亮。
- 不完整路徑回報未接通；有效路徑在 LOW 仍顯示接線正確，但 LED 熄滅。
- 只要導線使用本課不支援的其他板腳，就停止亮燈並說明。輸入專用、Flash 保留及非 GPIO 有專屬原因；其他 GPIO 提示本課固定 GPIO23。
- 導線與共地先合併電氣節點，再檢查兩個元件的串聯及極性，避免只比對三條固定範例字串。

這些是教學規則，沒有精確類比求解、電流或功率估算、硬體燒毀模擬、任意元件電路、Arduino 編輯器或 Blink 排程。

## 模型與視覺

沿用原介面灰白背景、深藍文字、綠色操作與細邊框。新增雙分頁、右側課程步驟／診斷／電位控制、下方端點群組與導線清單。LED、電阻、端點、導線均為自行生成的 Three.js 幾何；標籤原生繪製，不匯入外部照片或 GLB。

視覺草圖作介面參考，板型映射依官方資料。零件位置為示意，保持板在左、零件在右、控制在側；為保留現有相機與正確端點位置，3D 零件採上下配置，非照片級復刻。接腳資料、支援所有獨立 GND、診斷提示與頁面暫存說明優先於草圖未核對的標示。

## 驗證

18 項 Node 測試（原板型 4 項＋電路 14 項）通過，涵蓋正確 HIGH/LOW、全部 GND、電阻交換及放在 LED 後、反接、缺電阻、短路、元件旁路、刪線斷路、不支援腳、未知／重複／自連與狀態重設。

Playwright／Chromium 的 18 項課程檢查通過：手動接線、HIGH/LOW、刪線、各種錯接、鍵盤操作、取消、範例 LOW、模式切換保留、真實 3D 點 GPIO23 與電阻端點、WebGL 重試保留圖狀態、無 WebGL 操作、390px 排版、console 與未處理例外檢查。1440×1080 與390×844 截圖已檢視。此為軟體 WebGL 驗證，不等於使用者 Acer 的硬體效能紀錄。
