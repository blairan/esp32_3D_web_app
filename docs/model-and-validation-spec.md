# V4 簡化模型與驗收規約（Sprint 1 工作稿）

日期：2026-10-27（Asia/Taipei）。現行板型：[v0.2 決策](board-decision-v0.2.md)。本稿是交付規約，尚無實作與實機測試結果。

## 資料與模型契約

- 單板 `esp32-devkitc-v4-wroom-32e`，來源 [接腳 CSV](esp32-devkitc-v4-pins.csv)。不可在 React、Three.js 或教材各維護不同接腳排列。
- 正面看天線向上、USB 向下。板中心為原點，X 向右、Y 向天線、Z 向元件面外側；J2 在負 X，J3 在正 X。背面繞轉只改觀察位置，不交換接腳資料。
- 同側第 n 腳的符號座標為 `y=(10-n)*p`，J2 為 `x=-r/2`、J3 為 `x=+r/2`，n=1..19，p 是同側針距，r 是排距。p、r 尚待官方機構文件確認；不可代入舊 DOIT 或社群封裝數字後宣稱為 V4 實測。
- 所有接腳獨立生成實體幾何及選取區，包含電源、EN、三個 GND、六個 flash 專用腳；以 pinId 關聯，GPIO 編號可以為空，不以 GPIO 作實體唯一鍵。
- B4 背面圖的 54.4、27.9、48.2 mm 保留原始標註。待 dimensions/PCB 文件定義各段邊界後才填板體、模組伸出及 USB 的毫米座標。
- 建模分成板體、WROOM-32E 屏蔽罩／天線區、Micro USB、EN/Boot、電源 LED、兩列公排針。非教學必要的小型元件可省略；未畫出的元件不代表實板不存在。
- 幾何為自行建立；不使用外部 GLB、不將官方照片當材質、不以官方商標裝飾介面。來源留在說明文件供追溯。
- 提供 `geometryAccuracy: simplified` 與來源版本資訊；不能標成製造用 CAD 或精確電路模型。

## 選取與操作規約

- 預設視角看元件面並清楚辨認 USB／天線；重設回同一固定相機位置、目標點與縮放距離。確切相機值在實作時依模型包圍盒決定並保存。
- 工程預設：單指／滑鼠按下至放開移動超過 6 CSS px 視為拖曳，不執行接腳點選；雙指手勢取消點選候選。此數值是待實機調整的操作參數，非硬體資料。
- 選取區要方便點擊，且不互相覆蓋造成錯選；多個候選時採可見最近命中。弱裝置的簡化模式仍保留全部接腳與相同 pinId。
- 鍵盤清單依 J2-01..19、J3-01..19 呈現有名稱的原生按鈕；Tab 導覽、Enter/Space 選取、可見焦點。3D 與清單共用 selectedPinId，使用者不需操作 3D 才能讀取接腳資訊。
- 只允許一個 selectedPinId；更換接腳後舊高亮清除。沒有 GPIO 編號的電源／EN／GND 不顯示虛構 GPIO。
- flash 專用腳可選可讀，清楚說明禁止一般接線；輸入專用腳不可描述為可輸出。板載電源 LED 不提供 GPIO Blink 控制。
- WebGL 不可用時提供可理解的提示，保留接腳清單與資訊；載入錯誤與進行中狀態分開。
- 桌面左右配置、窄螢幕上下配置，沿用 v0.1 草圖。觸控不能依靠 hover 才能讀取資訊。
