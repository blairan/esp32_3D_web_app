# 練習自動保存與檔案交接

2026-10-31（Asia/Taipei）。適用 ESP32／UNO R3 的全部18課，各板各課各自保存。

## 使用方式

標題下方新增「練習保存」區塊，顯示本機保存結果及「匯出練習／匯入練習」。程式、接線、範例接線的原始備份與輸入設定會在內容改變時保存至此瀏覽器；不把虛擬時鐘更新寫入儲存。

- 重新整理同一網址會載入該板型／課程草稿；未指定板型、課程及模式的首頁會接續上次保存的板型／課程，進入程式練習。明確指定的既有網址優先。
- 切換專題或板型先確認停止執行，保留目前草稿並載入目的課草稿。沒有草稿才使用空架構；不同板型同名課程不會互相覆蓋。
- 每次「匯出練習」只下載目前板型／課程的JSON檔案。換電腦後開啟同一網站，按「匯入練習」選擇該檔案；確認訊息顯示目的板型與專題，確認後覆蓋該格草稿並導航至正確工作台。
- 有效但尚未完成、甚至含語法錯誤的程式也可保存。匯入不執行程式，不以語法解析器拒絕未完成練習。
- 程式一律從未執行狀態還原：不保存Worker、虛擬時間、變數值、示意音、手動HIGH／PWM輸出、按住按鈕、視角或待接端點。伺服回初始示意角度。使用者須主動按執行。

保存的輸入包含電位器／光照ADC、理想溫溼度、距離、有無回波、PIR活動及模擬感測失敗。清空接線或重建架構會更新該格草稿；範例顯示期間重新整理，仍可再次隱藏並恢復原本接線。

## 檔案與儲存介面

`Practice` 使用 `format: interactive-lab-practice`、`version: 1`，包含 `boardId`、`lessonId`、`source`、`wires`、`backup`、`inputs`、`savedAt`。只保留已知欄位；不使用eval、任意物件合併或檔案提供的URL。

本機鍵為 `interactive-lab-practice-v1:<boardId>:<lessonId>`；首頁快捷索引為 `interactive-lab-last-practice-v1`，只指向可驗證草稿。版本、板型、專題必須受支援；程式上限12000字元／400行，每組導線最多12條，端點必須屬於該板及課程，不接受重複ID、自連、重複導線或超大數字編號。輸入值依板型驗證，UNO ADC不接受1024以上。匯入檔案最多128KiB，包含UTF-8實際位元組檢查；未支援版本直接拒絕。

接線不必已通過電路驗收，允許保留練習中的錯接；未知端點或損壞結構則拒絕。匯入先完整驗證、再確認、再寫目的格，寫入成功才停止程式及導航。舊頁的卸載處理不覆寫剛匯入的內容。

## 失敗處理與限制

- 損壞的本機草稿顯示提示，不在初次載入／React StrictMode重播時自動覆寫原資料；使用者修改後才建立新保存內容。
- 儲存遭封鎖或空間不足時，顯示無法保存並提示匯出；檔案匯出仍可使用。若本機無法寫入，匯入不更動目前程式與接線，也不停止既有執行。
- 取消匯入或檔案錯誤均不覆蓋目的格。重新匯入相同檔名仍可操作。
- 關閉未修改的舊分頁，不會重新寫回舊內容蓋掉其他分頁的最新保存；若多個分頁實際編輯同一課，仍以最後保存為準，沒有多人協作或衝突合併。
- 沒有登入、後端、雲端同步或自動跨裝置傳輸。清除網站資料、瀏覽器設定檔遺失或無痕視窗結束，都可能使本機草稿消失；需要持久備份時請下載JSON檔案。外觀偏好維持原有獨立機制，不包含在練習檔。
