# 第十五、十六課：DHT22 溫溼度與 OLED 文字顯示

2026-10-28（Asia/Taipei）。沿用 DevKitC V4／WROOM-32E 38 腳、一次兩課、空架構練習與既有 GitHub Pages 流程。

## DHT22：climate-dht

- 三腳、DATA 已上拉至 3.3V 的模組模型：VCC → 3V3（J2-01）、DATA → GPIO4（J3-13）、GND → 任一 GND。GPIO23 另串聯 220 Ω／LED，共六條範例線。不是裸四腳感測器的腳序；實板須核對模組與上拉條件。
- 單一全域 `DHT climate(4, DHT22);`，物件名稱可變；建構子只接受整數腳位常數，begin 時檢查必須是 GPIO4。`climate.begin()` 後，函式內可讀 `readTemperature()`／`readHumidity()`。
- 整數理想輸入 -40～80°C、0～100%RH；兩方法共用第一次立即取得、此後每 2000ms 才刷新的樣本。同時顯示即時值、最近樣本與樣本虛擬時間；滑桿不直接控制燈。
- 參考練習每 2000ms 讀取，溫度 ≥30°C 或溼度 ≥80%RH 亮燈。使用巢狀 if／else，沒有開放 `||`；輸出仍須先 OUTPUT。
- 接線失效或勾選「模擬讀取失敗」時，下一次需要新樣本的讀取診斷停止；未到更新期限的舊快取仍有效。錯誤／停止／重設清除樣本與 LED，暫停保留。
- 實際 Adafruit DHT 函式庫回傳 float，失敗回 NaN，需要實板程式的 `isnan` 檢查；本模型用整數與診斷，不提供浮點、NaN、波形、雜訊、暖機或完整函式庫。實板需安裝 DHT sensor library／依賴並加入 DHT.h；模擬器不接受標頭或載入原生程式。

## OLED：oled-i2c

- 128×64 單色 SSD1306、3.3V I²C 模組，假定含拉至 3.3V 的上拉：VCC → 3V3、GND → GND、SDA → GPIO21（J3-06）、SCL → GPIO22（J3-03），四線範例，固定 7 位址 0x3C（60）。不以 GPIO 輸出或電流粒子假裝求解 I²C 電氣行為。
- 單一全域 `Adafruit_SSD1306 display(128,64,&Wire,-1);`，名稱可變；`&Wire` 只在此固定建構子接受。先 `Wire.begin(21,22)`，再 `display.begin(SSD1306_SWITCHCAPVCC,0x3C)`；錯誤腳位、地址、缺初始化或接線直接診斷。
- 支援 `clearDisplay()`、`setTextSize(1/2)`、`setTextColor(SSD1306_WHITE)`、`setCursor(x,y)`、`print`／`println` 的 ASCII 字串或整數、以及 `display()`。不開放任意方法、指標、格式化字串、中文字庫、圖形、黑色覆寫、浮點數、真實函式庫或直接 GPIO 讀寫。
- 緩衝與已提交畫面獨立；clearDisplay 只清緩衝、不重設游標、不立即改螢幕。print／println 後呼叫 display 才同時更新預覽及既有 3D 場景紋理，不重建編輯器或場景。
- 文字使用近似字形與 6×8 格；大小 1 或 2，自動換行及裁切超出高度的字。游標 x 0～127、y 0～63；單字串上限 80 字元、緩衝 256 個可見字元，僅支援換行、引號與反斜線跳脫。這不是逐像素 Adafruit GFX 重現，字元重疊也只作簡化繪製。
- 範例每秒顯示標題及整數計數。暫停保留畫面、變數與時間；停止／重設／錯誤清空，接線失效隱藏畫面。真實 OLED 斷電／停止狀態不由本模型保證。
- 實板需 Wire、Adafruit GFX／SSD1306 標頭與函式庫，另檢查 begin 的布林結果、模組電壓與地址。本教學初始化失敗直接診斷，沒有任意 C/C++ 編譯。

## 共用與驗證

- 兩課都有 3D 元件／可鍵盤操作端點、範例顯示／隱藏恢復原線、空白架構、隨物件名稱補全／參數提示／Wiki、主動展開標準答案；Wiki 24 篇。Worker 保留 revision、停止取消、來源／操作／虛擬時間限制及無正值 delay 防護。
- 151 項單元測試通過，新增 13 項覆蓋接腳、拓撲、短路與 5V、取樣精確邊界／快取／失敗、警示門檻、綁定與初始化、畫面提交／清緩衝、地址／匯流排、游標／換行／裁切／上限、ASCII 跳脫、名稱／字串與語法隔離、預算、範例重設。
- TypeScript／Vite 正式建置通過；保留既有大型 chunk 提示，不將它標成建置失敗。
- Browser plugin 未提供，使用 Playwright Chromium／軟體 WebGL／正式 dist 子路徑。實際 Worker 的 DHT 警示、取樣、失敗、暫停原始值與樣本差異、Wiki／續跑／停止／重設；OLED 計數、延後提交、清緩衝、地址及斷線診斷、重新命名、補全與參數 Wiki；320／390px 程式與 Wiki、桌面 1440px、原十四課載入與範例接線回歸，無應用程式 console error 或未處理例外。

- Wiki 文章含官方 Arduino／Espressif／Adafruit 來源。網址格式與站內對照通過；六個外部網址的 HTTP 請求遭本環境代理 403，未聲稱線上可用性已驗證。
- 未量測 Acer Aspire5／Win11／Chrome FPS、實體感測器、I²C 波形或真實手機；不得將軟體模擬當成硬體驗收。
