# UNO R3：18 課適配與驗證交接

2026-10-28（Asia/Taipei）。本輪完成 UNO R3 主排針探索及全部18課；不是完整AVR／電路模擬，也不是實體硬體驗收。

## 板型與狀態

右上「開發板」選 ESP32／UNO R3。網址 `?board=uno-r3&lesson=blink#code`；不帶board或無效值保留ESP32預設。切換遇到程式、接線、輸入／輸出或執行狀態時確認；取消保留全部練習，確認後停止Worker並完整導航至相同專題的新板型，清除程式／接線／視角／輸入。外觀沿用原本localStorage，不宣稱跨裝置同步。

每頁只使用一個固定的 BoardDefinition，避免切換時殘留另一板型的模組快取與閉包；Worker啟動訊息及Program攜帶boardId，執行器查各板的原生腳位與能力。UNO程式以D10=10、A0=14等原生Arduino編號執行，沒有將UNO指令轉成ESP32腳位。

為降低既有18課的回歸風險，保留ESP32接線分析與工作台；UNO以原生圖分析／工作台適配課程，共用板型登錄、3D操作、元件模型、編輯器、AST、Worker、外觀、Wiki容器與參考答案元件。此為實作層的拆分，使用者仍在同一網站切換板型。

## 模擬限制

- 沿用32位元整數與既有操作／虛擬時間預算，沒有重現UNO AVR 16位int、溢位、完整CPU、中斷或函式庫原生執行。
- DHT用理想整數及2000ms快取；實板float／NaN與失敗處理須另寫。OLED保留緩衝與display提交；真實初始化回傳值須另處理。
- UNO OLED必須採5V邏輯相容且具所需電位轉換的模組；不能把常見3.3V訊號模組一律視為可直接5V。PIR及其他實板訊號閾值與供電仍須查規格。
- TM1637亮度只驗證範圍；PWM、ADC、光照、聲波、電流與機械位置為教學示意，不作精準電氣或效能承諾。伺服由外部電源供電並共地。
- 沒有新增登入、後端、實體USB連線、燒錄、UNO R4、任意C/C++編譯或跨裝置進度保存。
