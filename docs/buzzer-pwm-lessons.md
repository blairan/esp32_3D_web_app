# 第七、八課：主動式蜂鳴器門鈴與 PWM 呼吸燈

2026-10-28（Asia/Taipei）。沿用 DevKitC V4／WROOM-32E 38 腳資料與既有 GitHub Pages 靜態流程。

## 第七課 buzzer-doorbell

- 教學元件為「內建驅動且 3.3V 相容的三腳主動式蜂鳴器模組」，不是裸兩腳負載，也不是指定商品已驗證的實物接法。
- GPIO23（J3-02）→ S；3V3（J2-01）→ VCC；GND → 模組 GND。GPIO18（J3-09）→ 按鈕 A 側，B 側 → GND，共五條範例線。
- GPIO 僅提供訊號。供電／接地／訊號缺線或互換，不顯示發聲；供電與 GPIO 短接、不支援接腳與按鈕跨接模組皆診斷。地腳可共用。
- 程式以 INPUT_PULLUP 與單一 if／else 控制 GPIO23；按下 LOW 時訊號 HIGH 發聲、放開 LOW 安靜。每 20ms 輪詢；不新增 tone、被動蜂鳴器、音樂或精確聲學。
- 3D 模組、S/VCC/GND 端點與發聲光圈。電流箭頭僅沿供電／接地導線示意，不把 GPIO 當負載供電。
- 聲音預設關閉，需使用者點擊開啟 Web Audio 低音量示意音。暫停保留訊號但停止聲音；放開、停止、視窗失焦、背景分頁與切換專題均停止或釋放。切換／卸載關閉 AudioContext，聲音無法啟用仍可看狀態。
- 手動頁可測試 HIGH／LOW；這與程式門鈴分開。範例切換仍會恢復原接線並清除手動輸出。

## 第八課 pwm-breathing

- 沿用 GPIO23 → 220 Ω → LED → GND 的三線接法。
- 僅此課增加 `analogWrite(23, duty)`，整數 0～255，教學固定 8 位元／1000Hz，先設定 OUTPUT。
- 允許受限全域變數、賦值、加減、millis 與最多四層 if；沒有 analogRead、ledc API、自訂頻率、乘除、for／while 或任意編譯。其他七課拒絕 analogWrite。
- 參考解法由 0 開始，每 30ms 改變 5，到 255 反向、回 0 再反向。1530ms 到 255，3060ms 回到 0。
- 3D 材質發光、光圈與電流示意隨佔空比調整，文字／亮度條顯示 duty 與百分比；錯接不顯示有效亮度。這是平均亮度示意，不是精確電壓、電流、人眼線性響應或逐個脈衝求解。
- 手動頁提供可鍵盤操作的 0～255 滑桿；程式頁顯示輸出 duty、最近 PWM 紀錄及全域整數。停止／重設清除輸出，暫停保留 duty 與時間。

## 教材與互動

兩課皆保留空架構、課程補全、參數提示的 Wiki 連結、主動展開的標準答案與範例接線顯示／隱藏。Wiki 新增兩篇，總計 16 篇，來源包含 Arduino Digital Pins／digitalWrite、Espressif DevKitC V4 與 Arduino-ESP32 LEDC／analogWrite。外部官方連結僅檢查格式與對照，未在此次環境做 HTTP 可用性驗證。

課程切換檢查找出參考答案與輸出元件使用同一 React key 的問題；已給輸出元件獨立 key，並以實際切換驗證沒有殘留答案或音訊。

## 驗證與限制

- 102 項單元測試通過：新增 10 項涵蓋模組接線、缺線／互換／短接／跨接、供電方向、20ms 門鈴讀取、PWM 範圍／模式／接腳限制、0／128／255、漸變時間邊界、滑桿與範例重設、舊課語法隔離。
- TypeScript 與 Vite 正式建置通過，既有大型 chunk 提示仍在。
- Browser plugin not available，使用 Playwright Chromium、軟體 WebGL 與正式子目錄產物。
- 瀏覽器驗證兩課真實 Worker、按下／放開、預設靜音、實際 Web Audio start／stop／close、失焦／重新操作、暫停／Wiki／繼續／停止、課程切換、PWM 超界診斷、手動 0／128／255、3D 畫面亮度變化、範例還原、1280／390／320px，以及原六課載入與接線回歸。無未處理例外或應用程式 console error。
- 另驗證音訊拒絕及 WebGL 不可用時仍有可操作控制與文字狀態。
- 未量測 Acer Aspire5 FPS、真實模組電流／音量、實體 PWM 或實際手機。實物模組需另核對規格及驅動與保護設計。
