# 正弦波教學參考與佔空比曲線

2026-11-01（Asia/Taipei）。在既有LED／PWM波形區新增「圖形種類」，三板型沿用相同互動與外觀。沒有新增DAC、RC濾波、類比電壓模擬、編輯器語法或實板量測。

## 圖形選擇

- **LED數位／PWM參考波形**：保留原有資料、來源選擇與操作。
- **正弦波教學參考**：獨立數學圖，可在未寫完程式、未接線或程式執行中查看。調整參數立即更新，不必按「執行」。不輸出到GPIO，不改動程式、元件、虛擬時鐘或執行狀態。
- **佔空比變化曲線**：只在PWM／RGB／電位器調光課出現，使用既有VM記錄，以各板型255／65535最大值轉成0～100%。只表示平均亮度的教學趨勢，不等同實測光強。

原有純顯示器、伺服、蜂鳴器課不硬套LED波形。原有波形可選課程共33課，全部41課仍保留各自的功能。

## 正弦參考契約

公式為 y(t) = A × sin(2πft)，公式中的t以秒計，圖形橫軸使用毫秒。縱軸固定-2～+2，使用無單位的相對值，因此調大振幅會實際擴大曲線高度；負值不是接腳負電壓。

| 控制 | 預設 | 可用範圍 |
|---|---|---|
| 頻率 | 1 Hz | 0.5～10 Hz，滑桿每次0.5 Hz |
| 振幅 | 1 | 0～2，滑桿每次0.25，無單位 |
| 時間範圍 | 2000 ms | 200／500／1000／2000 ms |

顯示週期1000/f毫秒、峰對峰2A。振幅0時為零值水平線。圖中的t=0為獨立參考起點，沒有套用程式虛擬時間或聲稱實際PWM相位。圖形是可調參數的靜態參考，不增加動畫時鐘。

純函式`sineReference(SineParameters)`產生最少121、最多961個有界取樣點，每週期至少48段；不解析任意公式或執行使用者JavaScript。React memo及useMemo避免每次Worker回報都重算不變的正弦路徑。

## 實際佔空比變化

- `signalSegments`共用已知狀態重建邏輯，保留`digitalSegments`原介面，新增`dutySegments`作百分比轉換。不改Worker、解析器或記錄格式。
- 每次PWM命令值保持到下一次寫入，呈階梯狀曲線；固定加減步長會呈三角形趨勢，不任意平滑或替換為正弦波。尚無PWM設定、數位模式區間或缺資料時留白。
- 保留原512筆環狀記錄及通道邊界，提供最近2／5／10秒與目前虛擬時間游標。暫停保持，停止／錯誤／重設／新執行清空。
- 曲線優先呈現，參數及數值區在其後，避免桌面首屏只有控制而看不到新圖形。

## 狀態、版面與相容

圖形選擇、正弦參數及曲線時間範圍由閱讀區局部管理；切換四步或圖形會保留設定，不重建編輯器或3D。停止／重設只影響程式及記錄，正弦參考仍可查看。換課、重新載入後採預設，不寫入JSON、草稿或雲端同步。

沿用響應式SVG、16px刻度及深淺背景配色。座標依面板寬度調整，手機減少刻度，另有公式、數值與ARIA解說。外觀選單仍維持在結果卡片上方。
