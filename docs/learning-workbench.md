# 三板型實驗手冊工作區

2026-11-01（Asia/Taipei）。本次只改教學介面與導航，沿用 ESP32／UNO 各18課、Pico 5課、已核對的板型模型及模擬器，不新增硬體、語法或課程。

## 設計與操作

依對話確認的灰白／石墨／暖橙設計：桌面左45%固定3D，右55%教學；1024px以下上下排列。頁面、面板、畫布及重點色仍可分別調整。正文17–18px、程式碼與主要控制16px；三板型共用標頭、四步列、執行及檔案工具列。

四個可自由切換的步驟：

1. 認識專題：目標、元件、預期現象、Wiki。預期現象不是已測結果。
2. 接線：3D／平面端點、接線清單、範例還原、錯接診斷、Wiki及手動輸出入口。Pico板載LED課明確不需外接線。
3. 寫程式：原草稿、補全、提示、主動展開的標準答案、支援限制。答案不自動填入。
4. 觀察結果：該課實際的輸出／變數／虛擬時間／取樣，不捏造未提供的量測資料。按鈕、ADC及感測器輸入在此調整。

## 狀態與兼容

- `LearningStep`為intro／wiring／code／results；共用外殼與持續掛載的隱藏區塊管理顯示。切換四步不停止／重建Worker、編輯器或3D，不清除程式、游標、undo、接線或視角。執行／暫停時仍鎖定編輯。
- 臨時指標／鍵盤按住會在切步時釋放；「保持按下」是明確的持續輸入，跨步保留。停止、換課、離開視窗等仍使用完整釋放。
- 手動輸出必須明確進入，先停止程式及清除輸出。切步不退出手動模式；啟動程式會退出手動模式，停止／重設清除手動輸出。觀察區與3D均使用有效控制來源。
- 程式執行中改壞接線會診斷並停止；初始無效接線不會產生有效電流效果。感測器及裝置的原有Worker診斷維持。
- URL保留board及lesson；#code、#led／#wiring仍有效；新增#intro、#results，#explore保持獨立。新選專題進入導讀，直接舊連結仍進原對應步驟。hashchange／popstate也同步步驟；普通清單錨點不誤切模式。
- JSON版本、草稿鍵、板型接腳與實板匯出器不變。新主題只作無既有選擇時的預設；舊配色不強制覆寫，使用者可明確套用新版配色，且不改電流效果選擇。
- Arduino／MicroPython共用語意高亮，文字顏色依面板調整到至少4.5:1。直接宣告原有傳遞依賴@lezer/highlight 1.2.5，沒有新增下載的runtime套件或瀏覽器依賴。
