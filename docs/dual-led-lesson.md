# 第三組專題：雙 LED 交替閃爍

2026-10-27（Asia/Taipei）。依使用者指示接續第三項，在既有網站新增雙 LED 專題，不改動原兩課的預設教材。

## 入口與學習目標

右上「學習專題 → 雙 LED 交替閃爍」，網址 `?lesson=dual-led#code`；選單「LED 接線」開啟此課手動測試頁。仍從空 setup／loop 架構開始，練習目標是先 LED 1 亮／LED 2 滅、等待，再交換狀態並等待。補全只提供既有 int、pinMode、digitalWrite、delay 及常數，提示新增 GPIO22；此課不開放按鈕課的 digitalRead／if 語法。

標準答案預設收合，使用 GPIO23 與 GPIO22，兩階段各 delay(1000)，完整週期 2000 ms。每個接腳都先設定自己的 OUTPUT；設定／寫入一個接腳不會自動改變另一個。使用者可主動查看與複製解說，不自動填入、執行或覆蓋原程式。

## 接線與模型

- LED 1（紅）：GPIO23／J3-02 → 電阻 1（220 Ω）→ LED 1 A+，LED 1 K− → 任一 GND。
- LED 2（藍）：GPIO22／J3-03 → 電阻 2（220 Ω）→ LED 2 A+，LED 2 K− → 任一 GND。
- 六條範例導線；各支路電阻 A/B 可交換，也可放在同一 LED 後面。GND 可共用，兩個輸出不可直接相連；不支援跨接兩條元件支路或共用一顆電阻。
- 第一組沿用原端點 ID resistor:a/b、led:a/k；第二組為 resistor2:a/b、led2:a/k。模型、點選區、原生端點與接線清單都可區分，第一組在本課明確標為電阻 1／LED 1。
- 兩列元件與 R1/R2、LED 1/2 標示；電流方向分支獨立，第二組單獨亮起時也能顯示流動。地線繞至兩列下方，避免穿過第二顆 LED 中心。顏色是輔助，狀態卡仍顯示文字與 GPIO。

## 電路診斷

驗證完整接線圖，先拒絕未知、重複、自連、超量（12 條）與非法 GPIO。wire-only 電氣節點共地後檢查直接短接與跨支路連接。任一輸出直接接地、兩輸出直接短接、或非 GND 支路跨接時，明確顯示故障並使兩顆不顯示導通，不嘗試類比求解。

其餘每條支路獨立套用既有 LED 規則。某顆斷路、反接、缺電阻、LED／電阻旁路時，該顆不亮並提供自己的標題與說明；另一條有效支路仍可亮。總接線提示列出兩條結果，狀態卡各自顯示 INPUT/OUTPUT、HIGH/LOW 與亮滅。手動頁支援四種組合，不強制交替；真正交替由程式安排。

## 執行器與狀態

課程定義新增允許輸出清單。ProgramSnapshot 新增以 GPIO 為鍵的 outputs 記錄，各含 enabled／level；每次快照複製記錄，避免外部修改解譯器狀態。保留 level／outputEnabled 作 GPIO23 相容欄位，原兩課顯示保持相同。

每個 digitalWrite 分別檢查對應 GPIO 已設定 OUTPUT，否則給出該腳位與行列診斷。TraceEntry 新增 gpio，本課訊號紀錄標示是哪個接腳。暫停保留兩組狀態；停止、重設、錯誤、Worker 失敗或換課都清除所有輸出，不能留下第二顆亮著。原 Blink／按鈕課仍拒絕 GPIO22。

場景傳遞兩個獨立 lit 值，更新材質／電流不重建場景或重設視角。課程切換的確認、取消、空架構及外觀偏好沿用既有規則；手動狀態也分開保存，進入程式頁會將兩組手動輸出回 LOW。
