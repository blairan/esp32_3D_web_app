# Pico 第6課：光敏電阻夜燈

2026-11-01（Asia/Taipei）。接續PWM與ADC基礎，新增 `ldr-nightlight`；Pico共6課、9篇Wiki，三板型合計42課。

## 練習與接線

入口：`?board=pico-2-w&lesson=ldr-nightlight#intro`。沿用四步工作區；預設只有Pin／ADC物件及待完成的pass，完整答案需主動展開，不自動填入編輯器。

- GP15（實體20）→220Ω限流電阻→LED A+／K−→GND。
- 3V3(OUT)（實體36）→光敏電阻LDR→GP26／ADC0（實體31）→10kΩ分壓電阻→GND。
- 兩個分壓元件各自沒有極性，交換A／B端有效；上下位置需依本課約定。此接法越亮LDR阻值越低，GP26電壓／讀值越高。
- 範例共7條線，可顯示及還原原接線；兩顆電阻用途不同，不可用10kΩ分壓電阻取代LED的220Ω限流電阻。

分壓與LED支路各自檢查，拒絕5V、錯誤GPIO、訊號直接接電源／地、分壓上下位置交換、跨接LED支路、元件旁路、缺線、LED反接及缺限流。接線無效會診斷並停止程式，清除輸出。電流亮點只沿驗證通過的LED路徑，不流過ADC輸入線。

## 程式與觀察

`from machine import Pin, ADC`，一個GP15數位LED、一個 `ADC(Pin(26))`，支援物件改名、`.read_u16()`、有號32位整數變數／加減與單層整數比較。沿用on／off／toggle、正值等待及執行預算。不開放PWM、任意Python、巢狀分支或其他ADC腳；前五課的語法範圍保留。

標準練習每50ms取樣：read_u16小於24000時開燈、大於35200時關燈，包含兩邊界的中間區間不改輸出。架構先呼叫led.off()，初始LED明確為關閉。這是雙門檻遲滯，門檻是教學值，實板應依環境校正；使用者的程式仍可改門檻、等待與判斷方式。

結果區輸入為12位元0～4095，依既有RP2位元展開 `(raw << 4) | (raw >> 8)` 轉成0～65535；中點2048對應32776。區分即時值、程式上次樣本、變數與實際LED數位波形。暫停保持樣本／輸出，繼續後才讀取新值；獨立正弦波參考仍可查看，不把LED數位輸出當成正弦訊號。

3D新增簡化LDR圓片與獨立10kΩ電阻，並提供較大點選區及鍵盤端點。控制區是理想ADC輸入，不計算光敏阻值、lux、雜訊、電流或真實電路，不將LDR畫成發光元件。
