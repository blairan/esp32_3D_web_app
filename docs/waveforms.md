# LED 數位波形與 PWM 參考

2026-11-01（Asia/Taipei）。在既有三板型工作區的「觀察結果」加入波形；不增加硬體板型、語法、ADC折線圖、實板量測或示波器功能。

## 使用方式

- LED 數位圖依程式實際輸出變化與虛擬時間繪製 HIGH／LOW，提供最近2／5／10秒範圍、目前程式時間游標、程式行號與最近輸出數值表。雙LED／交通號誌可選通道。
- PWM提供「跟隨目前程式」或25%／50%／75%參考，顯示三個理想週期、佔空比、週期T、高／低電位時間。RGB可選三個通道。
- UNO／ESP32使用1000Hz作放大參考，明確不是analogWrite實際頻率；Pico有程式freq設定時沿用它，尚無設定時參考圖使用1000Hz。比率使用Arduino duty／255與Pico duty_u16／65535，不把128或32768誤稱精確50%。
- 純參考值不改變程式、接線、輸出、執行／暫停或模擬頻率。程式尚未有PWM輸出時，「跟隨程式」不畫假資料，但可以自行選固定參考。
- 暫停與切換四步保留程式波形；停止、錯誤、重設或重新執行清除執行記錄。手動模式不記錄程式波形。使用者選定的純PWM參考值可繼續查看。
- 輸出圖適用LED相關課程，共33課；伺服、蜂鳴器、純OLED與七段顯示不硬套LED圖。超音波及整合課僅顯示警示LED，不把TRIG或I²C當LED。

## 記錄與介面

`ProgramSnapshot`及`PythonSnapshot`新增內部`waveform: SignalHistory`。每筆為channel、timeMs、digital／pwm、value及可選frequency。Arduino沿用實際原生GPIO編號，Pico板載LED使用獨立通道-1，外接LED使用GP15。

- Arduino在pinMode OUTPUT、digitalWrite與analogWrite執行時記錄，原有最近8筆trace完全保留。Pico使用排程readyAt記錄on／off／toggle／duty／freq；不以畫面輪詢時間代替語句時間。
- 以環狀buffer保留512筆變化，相同通道的相同狀態不重複累積；另保留每通道最後捨棄的邊界狀態，避免另一個通道快速切換後，持續不變的輸出反而消失。空白／未知期間不猜測為LOW，已捨棄的振盪不補畫。
- Worker傳送有界快照；SVG依收到的虛擬時間更新，沒有新的動畫時鐘、插值或任意程式執行。PWM圖為目前參數的理想形狀，不假裝逐脈衝求解、實際相位、實板電壓或LED電流。
- 圖表隨實際面板寬度配置座標，維持16px刻度；窄畫面減少刻度數量，另有數值與表格供鍵盤／閱讀器使用。隱藏步驟不將寬度歸零，切回時保留圖表尺寸與閱讀選項。
- 波形僅在本次執行記憶體中；JSON練習格式、草稿鍵、.ino／main.py輸出與課程支援範圍不變。
