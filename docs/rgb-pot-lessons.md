# 第九、十課：RGB 混色與電位器調光

2026-10-28（Asia/Taipei）。沿用一次兩項的順序開發及現有 38 腳 DevKitC V4／WROOM-32E，沒有更換板型。

## RGB 混色 rgb-mixing

- 共陰極四腳 RGB 教學模型：GPIO23（紅）、GPIO22（綠）、GPIO21（藍）各經自己的 220 Ω 電阻，再到 R／G／B；K− 接 GND。共七條範例線，沒有套用某個實物 RGB 腳序。
- 三色獨立 0～255 analogWrite，逐腳先設定 OUTPUT。沿用受限狀態語法，沒有 ADC、除法、乘法、共陽極或 ledc API。
- 手動頁三個原生可鍵盤操作滑桿、RGB 數字與色塊；程式頁顯示真實執行器的三路輸出。3D 單顆 RGB 模型、四個端點與三個電阻，材質顏色由有效支路混合。
- 個別斷路、缺電阻或反接只使該色無導通；共陰極缺地使三色皆斷路；輸出互接、短地及非接地跨色連接使整組無導通。每色投影到已驗證的單 LED 串聯規則，共地不合併物理接腳物件。
- 參考答案紅 → 黃 → 白，每階段 1000ms，完整週期 3000ms；每階段明確設定三色。
- 顏色為理想加色示意，不做 gamma、LED 效率、色溫、白平衡或實物光學校正。

## 電位器調光 pot-dimming

- VCC → 3V3（J2-01）、W → GPIO34（J2-05）、GND → GND；LED 沿用 GPIO23 → 220 Ω → LED → GND。共六條範例線。
- GPIO34 的 J2-05 位置與只能輸入限制經既有板型資料測試；INPUT 不含內部上拉。
- 固定電位器端點方向；供電、ADC、輸出跨接或缺線返回未確認輸入，不猜浮接讀值。不接受 5V 或將 ADC 直接接其他 LED 節點。
- 理想旋轉輸入 0～4095。只有此課開放 analogRead(34)、GPIO34 INPUT 及整數除法 `/`；除法先於加減、向零截斷，除以零與 32 位元溢位都診斷。
- 參考答案每 50ms 讀一次，reading / 16 取得 0～255，再 analogWrite(23, brightness)。不是自動將旋鈕綁定 LED。
- 即時 ADC、程式上次讀值及 PWM 分開顯示。暫停可轉旋鈕，但上次讀值、PWM 與虛擬時間保持；繼續時將最新輸入送入 Worker，執行下一次讀取才更新。
- GPIO34 不可輸出；不支援 analogReadMilliVolts、map、浮點、乘法、衰減設定、雜訊或精確 3.3V 滿刻度換算。停止／重設清除上次讀值與輸出。
