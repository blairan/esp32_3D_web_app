# 第十一、十二課：光敏電阻夜燈與伺服角度控制

2026-10-28（Asia/Taipei）。沿用一次兩項節奏與既有 DevKitC V4／WROOM-32E 38 腳資料。

## 光敏電阻夜燈 ldr-nightlight

- 七線範例：LED 用 GPIO23 → 220 Ω → LED → GND；感測支路用 3V3 → 光阻 → 分壓點／GPIO34（J2-05）→ 10 kΩ → GND。
- 光阻與 10 kΩ 皆無極性，允許各自交換兩端；分壓方向固定為暗時 ADC 低、亮時高。10 kΩ 不是 LED 的限流電阻。
- 光照滑桿提供 0～4095 理想 ADC 教學值，不是 lux 或精確阻值、分壓電壓、雜訊或完整量程保證。實物需量測與校準。
- 參考解法每 50ms 讀取；小於 1500 開燈、大於 2200 關燈，1500～2200 保持原輸出；初始 OUTPUT 為 LOW。兩個門檻形成遲滯，與時間去彈跳不同。
- 模擬包含原始光照輸入、程式上次讀值、輸出與 3D 狀態。暫停可改光照，讀值與輸出保留，繼續後才重新取樣。
- 缺線、供電短接、分壓元件旁路及跨 LED 支路皆使 ADC 未確認並診斷，不猜測浮接輸入。LED 支路仍另行驗證。
- 只新增本課 analogRead(34) 與 INPUT，沿用受限整數、比較與 if；不開放除法、analogWrite 或實際照度換算。

## 伺服角度 servo-angle

- 四線範例：GPIO23 → SIG；外部 5V → VCC；外部 GND → 伺服 GND；外部 GND → 開發板 GND。地腳可選同網其他物理 GND。
- 不允許改用板上電源腳或將 GPIO 當馬達電源。外部電源／訊號／接地短接、供電互換或缺共地皆無有效控制示意。
- 白名單新增一個全域 `Servo name;`、`name.attach(23);`、`name.write(angle);`。名稱可自行指定；編輯器補全與參數 Wiki 跟隨名稱，不重複插入物件前綴。
- attach 後模型初始為 90°；write 必須先 attach，角度僅 0～180 整數，超界診斷，不將大值當微秒。參考解法 0／90／180° 各一秒。
- 支援有限 int 狀態、加減、if、millis 與 delay，仍保留來源／語法／操作／虛擬時間預算。不接受第二物件、區域 Servo 宣告、與物件同名 int、任意屬性、detach／read、微秒寫入、pinMode／digitalWrite／PWM／ADC 混用、任意 C++ 或函式庫執行。
- 實板須安裝 ESP32Servo 並加 `#include <ESP32Servo.h>`；本模擬器不執行標頭。Wiki 清楚區分模擬契約與完整函式庫。
- 3D 伺服搖臂直接呈現理想角度，沒有速度、慣性、負載、扭力或機械端點求解。暫停保持角度，停止／重設清除控制，示意模型回 90°；這不代表實物斷電會自動歸位。
- 電流方向只標示供電導線，不代表精確馬達電流或 GPIO 供電。
