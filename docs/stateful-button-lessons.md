# 第五、六課：按下事件與計數

2026-10-28（Asia/Taipei）。沿用 DevKitC V4／WROOM-32E 38 腳、GPIO18 INPUT_PULLUP、GPIO23 OUTPUT、常開按鈕與獨立 220 Ω LED 支路。兩課各五條範例線，顯示／隱藏會備份還原原本導線。

## 第五課 button-toggle

有效按下切換 LED，長按不重複，放開保持。參考解法以全域整數保存上次讀值、穩定電位、最後變動時間與 LED 狀態。每次原始讀值改變重新計時，連續穩定至少 50ms 才接受變化，僅穩定 HIGH → LOW 時切換。

## 第六課 button-counter

沿用相同去彈跳與下降邊緣判斷，計數全域整數每次有效按下加一。LED 表示穩定按下狀態。全域變數觀察區顯示使用者自行命名的所有全域整數，沒有綁定 `count` 這個名字，不新增 Serial、OLED 或其他硬體。

兩課初始只給架構和註解；完整解法需主動展開。暫停保留變數、輸出與虛擬時間，暫停中短按不會補記成事件。停止／重設清除觀察區與輸出，重新執行從使用者程式初始值開始。重新整理仍不保存練習進度。

## 語法契約

僅第五、六課額外開放：

- `millis()`：函式內取得目前虛擬毫秒。
- 已宣告 `int` 的 `name = expression;`，尋找最近作用域；全域跨 loop 保留，區域每次進入重新建立。
- 整數 `+`／`-` 左至右計算，每個算式最多 32 項。沒有乘除、括號算式、++、布林邏輯、浮點數或指標。
- 單一 `== != > < >= <=` 條件，最多四層 if／else；不支援 else if。
- `digitalWrite` 電位可用 HIGH／LOW 或值為 0／1 的整數算式，其他值診斷停止。
- 仍保留來源、行數、token、陳述數、每 tick／總操作數、時間預算與取消機制；實際執行路徑須含正值 delay。參考解法取樣間隔 10ms。
- 整數有號 32 位元，超界診斷，不模擬實機 unsigned long 或 millis 回繞；虛擬時間上限一天，亦可能先到達總操作預算。

原四課不開放新賦值、算式、millis 或巢狀 if。編輯器補全依課程提供，參數提示中的 millis 可開啟對應 Wiki；亦修正未支援函式的提示不能讀取空項目。

## 教學範圍與來源

虛擬按鈕是理想接點，沒有自動彈跳產生器。去彈跳以測試注入輸入時間序列驗證；50ms 是本課門檻，實板必須依實際按鈕量測，不能將這些結果當硬體通過證據。

新增 Wiki `button-toggle`、`button-counter`、`millis-state`，總計 14 篇。引用 Arduino Debounce、StateChangeDetection、millis 官方資料；僅檢查連結格式與站內對照，外部網站未做此次 HTTP 可用性驗證。
