# 第二組專題：按鈕控制 LED

2026-10-27。依使用者核准計畫新增「按住亮、放開滅」，保留第一組閃爍課。這是受限語法與理想數位電路教學，不是完整 ESP32／Arduino 模擬。

## 課程與入口

右上「接腳探索」右側的「學習專題」下拉選單可選 LED 閃爍或按鈕控制 LED；切換後進入程式練習。網址為 `?lesson=button-led#code`，也可用 `#led` 檢查接線；原有無 lesson 網址與未知值使用閃爍課。修改程式、接線／待接端點、輸出／按壓或非 idle 執行狀態時，切換需確認。取消保留工作；確認停止 Worker，清除程式、接線、按鈕、選取並回初始視角，保留外觀。重整保留網址選課，程式與接線恢復該課空架構／空接線，沒有跨裝置學習同步。

`src/lessons.ts` 定義兩組課程的 ID、GPIO 角色與元件端點；解析器、執行器、接線 reducer、模型與補全按課程選擇。共同板型仍為 38 Pin ESP32-DevKitC V4，GPIO18 是 J3-09，GPIO23 是 J3-02，未修改既有接腳對照。

## 接線與按鈕

- LED 支路仍為 GPIO23、220 Ω、紅色 LED 與任一 GND，沿用電阻前／後、反接、短路、旁路等規則。
- 四腳常開按鈕：A1/A2 永久相通，B1/B2 永久相通，按下才連通兩組。GPIO18 接 A 側，B 側接任一 GND（可反向／使用同側另一腳）。範例共五條導線，只載入接線，不提供完整程式。
- 以 INPUT_PULLUP 解讀：放開 HIGH，按下 LOW。斷路有提醒並維持 HIGH；同側誤接或直接接地有提醒並維持 LOW，不假造按放效果。
- GPIO18 或開關跨接輸出、非接地 LED／電阻節點、電源或其他板腳時顯示無法判定，digitalRead 停止並提供行列診斷。LED 不在不安全接線中亮起。每課最多 12 條線。
- 只有有效 LED 輸出路徑顯示慣用電流效果；不對按鈕上拉支路偽造電流量值。

3D 按鈕帽與獨立操作按鈕支援按住；獨立按鈕另支援 Space／Enter。拖出／拖曳超過閾值、指標取消、失去捕捉或按鍵焦點時釋放瞬時來源；保持按下開關是獨立來源，短暫按放不取消保持。視窗 blur、頁面隱藏、離開模式或切換專題時釋放所有來源。3D 帽與接線端點為獨立點選區，右鍵／Shift 平移不觸發按壓。沒有 WebGL 時仍可操作原生端點、按鈕與程式。

## 新課白名單語法

原閃爍課的語法邊界保持不變。新課新增：

- `pinMode(18, INPUT_PULLUP);`；GPIO23 仍只能 OUTPUT，GPIO18 只能 INPUT_PULLUP。不支援普通 INPUT。
- `digitalRead(18)`，pin 可使用已宣告變數。只可放在函式內 `int` 初始值或 if 比較運算元，回傳 HIGH=1／LOW=0。不得在全域初始值、delay 或其他函式參數中任意使用。
- `if (left == right) { statements }` 或 `!=`，可選 `else { statements }`。兩邊可用整數、已宣告變數、HIGH／LOW 或讀取結果。
- 強制小括號與分支大括號；不支援巢狀 if、else if、邏輯／算術／大小比較、重新賦值、自訂函式或使用者迴圈。分支允許既有白名單陳述，區塊變數不外洩。

解譯器以框架堆疊保持分支進度及區塊作用域，delay 後接續原位置。每條實際執行的 loop 路徑都需有正值 delay。12,000 字元、400 行、4,000 tokens、256 個陳述、單次 60,000 ms 等既有預算與停止規則不變；沒有 eval／Function 或任意 C++ 執行。

## Worker 與狀態

啟動訊息帶 lessonId 與當下輸入；新增 input 更新訊息，resume 也帶最新輸入。訊息皆帶執行 revision，Worker 及主執行緒拒絕舊版本事件（包含錯誤），停止直接終止 Worker。

按鈕更新外部電位，不直接改變程式輸出。只有執行到 digitalRead 才更新上次讀值；輪詢 50 ms 節拍與使用者 delay 決定可觀察時機，短按可被漏讀，沒有宣稱硬體即時性。暫停時外部按鈕可改變，時間、輸出、上次讀值維持；續跑後下一次讀取才反映最新輸入。介面明確分別顯示即時電位與上次讀值。

## 編輯、教材與視覺

預設只有 setup／loop 與概念註解；補全按課程提供 digitalRead、INPUT_PULLUP 及空白 if／else 片段，並保留參數提示。預設不填入完整控制答案；可另行展開標準答案對照，不會覆蓋自己的程式。Wiki 新增按鈕／上拉、digitalRead、if／else 三篇（共九篇），更新原本 GPIO、pinMode 與導讀的課程界線。

桌面新課模型使用 sticky 工作區，向下閱讀／操作按鈕時仍可觀察模型；手機採單欄。按鈕內部連通、針腳方向與即時電位均有文字，不靠 3D 操作作為唯一入口。模型是簡化示意，不宣稱對應某個商品按鈕的實際腳位與額定；實板請核對元件資料表。

## 驗證與限制

- 60 項 Node 測試通過，包含原閃爍與板型，以及新課各接地／端點組合、接線故障、語法與作用域、等待續跑、每條路徑預算、補全及空架構。
- 21 項新課瀏覽器流程通過：實際 Worker、指標／鍵盤、保持與瞬時並存、拖出、blur、暫停／續跑、Wiki、補全、診斷、斷路／同側、真實 3D cap raycast、切課確認／取消、舊課邊界、320/390px、手動模式、未知網址及 console。
- 另五項檢查通過：CDP 模擬觸控按放、touchCancel、頁面隱藏釋放、無 WebGL 原生操作，以及執行中非法輸入停止 Worker／LED。原編輯器及 Wiki 以更新後九篇目錄執行回歸檢查。
- 截圖檢查桌面 1440×1080 與窄螢幕；使用 Playwright／Chromium 軟體 WebGL，Browser plugin not available。不等於 Acer Aspire 5、Edge 或真實觸控裝置效能驗收。
- 理想無彈跳數位開關；沒有接點彈跳、精確電阻／電壓電流、每按一次切換、韌體燒錄或實體連線。官方文件主站仍可能受環境代理限制，不把未能直接開啟的外部連結列為已驗證。

發布沿既有 main → GitHub Actions → GitHub Pages；需核對本次成功工作流程與公開新資產，才宣告上線。

## 導覽調整

依使用者要求將專題入口移至右上接腳探索右側，將 LED 接線收進同一下拉選單，移除標題上方的選擇器。選單的 LED 接線操作使用目前所選專題；兩個課程項目進入程式練習。重選目前課程僅返回程式頁，不清除程式／接線；換課才使用既有確認與重設。取消確認保持選單開啟及工作狀態。支援外點關閉、Esc 返回入口、手機兩列標頭與窄螢幕選單；Esc 不取消待接端點。10 項導覽瀏覽器檢查通過。
