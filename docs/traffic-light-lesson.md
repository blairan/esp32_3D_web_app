# 第四課：紅黃綠交通號誌

2026-10-28（Asia/Taipei）。沿用 ESP32-DevKitC V4／WROOM-32E 的 38 腳資料，未增加板型或語法。

## 教學契約

- 紅 GPIO23（J3-02）、黃 GPIO22（J3-03）、綠 GPIO21（J3-06），各有一顆 220 Ω 電阻、獨立 LED A/K 端點，可共用 GND。
- 接線範例九條；顯示／隱藏沿用備份還原機制。程式文字、視角不因範例切換重建。
- 初始程式僅 setup／loop 架構。補全提示列出三個輸出；完整答案需主動展開，不自動覆寫練習。
- 目標：紅 3000ms → 綠 3000ms → 黃 1000ms，7000ms 重複；各階段先關前燈再開下一燈。
- 每個 GPIO 都須先設定 OUTPUT；不開放 digitalRead、if、PWM、算式或任意 C/C++。
- 三張狀態卡明示顏色名稱、GPIO、模式、電位、亮滅與接線診斷，識別不只依賴顏色。
- 手動控制可呈現所有八種組合；不偷偷強制單燈。三燈時序由使用者程式安排。
- 3D 三組模型、端點、材質及電流路徑獨立；課程切換與停止／重設清除三輸出，暫停保留。

## 接線規則

每支路沿用單 LED 串聯規則：可交換電阻兩端或放在 LED 後。開路、反接、缺電阻分別診斷，健康支路仍可亮。輸出短接、直接接地、跨支路非接地節點及不支援端點使整組無導通示意。這是離散教學模型，不求解類比電流，也不代表真實交通控制器。
