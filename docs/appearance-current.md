# 外觀與電流示意更新

日期：2026-10-27（Asia/Taipei）。使用者要求電流效果、可調整且不偏綠的配色，以及同時改善實際網頁的模型與排版。先前較逼真的畫面是視覺草圖，本次修改的是實際可操作網站；仍保留簡化教學模型的正確界線。

## 電流方向

- 接線圖驗證通過且 GPIO23 有效輸出 HIGH 時，沿導線及電阻／LED 的有效串聯路徑呈現移動亮點與方向箭頭；LOW、斷路、短路、反接或無效腳位不呈現電流。
- 方向是由 GPIO23 朝 GND 的**慣用電流**。與使用者先點哪一端無關，支援反向建立導線、電阻 A/B 交換、電阻位於 LED 後、不同接地及並聯接地回路。純 GND-to-GND 冗餘線不顯示假流動。
- 亮點數量、速度、亮度皆為固定視覺示意，不表示電子速度、電流 mA 或精確類比模擬。接線清單改用雙向連線符號，避免建立順序被誤認成電流方向。
- 「電流效果」可切換並記住本瀏覽器偏好；關閉效果不會改變 LED 或程式輸出。程式暫停凍結亮點，停止／錯誤則隨 LOW 熄滅。
- 系統 prefers-reduced-motion 或簡化模式改用靜態方向箭頭。只有有效流動時持續重繪，裝飾動畫上限 30 fps；相機直接操作仍按需回應。背景頁面停止重繪，沒有把 30 fps 上限宣稱成 Acer 實機效能測試。

## 外觀與保存

右上「外觀」提供深藍（預設）、紫羅蘭、暖橙、石墨及原生自訂主色選擇器。以 CSS 色彩 tokens 同步按鈕、選取、提示、接腳與元件端點；危險／注意、LED 紅色及導線區別色保留語意。

自訂主色依亮度選擇黑／白前景，並生成可閱讀的強調文字色、淡底、邊框及焦點樣式。白、黃等極亮色也檢查文字對比。偏好只存本機瀏覽器 localStorage 的 `esp32lab-appearance-v1`，內容只有 accent 與 flow；讀取錯誤、格式不符或儲存被封鎖時安全回復／保持當頁可用，不儲存程式與接線、不做跨裝置同步。

## 實際模型與版面

- 改善 PCB／模組／USB 的邊緣、程序生成板面細節與柔和接觸陰影、金屬環境反射，以及 LED 透明罩與電阻端帽。
- 表面紋理與走線僅是裝飾，不代表實板 PCB 佈線。沒有冒用照片、外部模型或將視覺草圖當成硬體規格。
- 電阻與 LED 改採左右串聯擺放，接地線繞下方；範例改用同樣有效的 J3-07 GND，板型接腳映射與支援的三個 GND 未改。
- 新的預設視角依畫布比例完整框住板與元件。使用者已平移／旋轉／縮放時保留視角；按重設重新取景。主色切換不重建場景或重設程式。
- 調整面板比例、文字層級、留白、淡底與邊框；手機採兩列標頭，保留清楚分頁與外觀入口，320px 也不橫向溢位。

## 區塊背景補充（2026-10-27）

原本「外觀」只調整主色，使用者指出實際網站缺少背景調整。現已加入頁面、面板、3D 畫布三個獨立原生色彩選擇器，以及「還原背景」。沿用同一瀏覽器偏好儲存；舊版設定自動補入預設背景，非法值逐欄回復預設。前景依背景對比調整，3D 外接元件標籤加淺底以便深色背景閱讀。變色不重建場景，不改變接線、LED 或程式狀態。

43 項單元測試通過；Playwright（Browser plugin not available）驗證 LED 頁三個實際背景、場景保留與 HIGH 狀態、重新載入保存、還原、320/390px 選單及無未處理例外。桌面 1440×1080 與手機 390×844 已檢視截圖；本次不是完整深色主題重設，按鈕與程式編輯器保留淺色背景。
